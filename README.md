# gitender

Git-friendly, rendering-ready JSON export of `sumatora.db` (the compiled Sumatora dictionary database),
generated by [SumatoraIndex](https://github.com/HappyPeng2x/SumatoraIndex)'s `sumatora-to-git.py`. Unlike
`gitmdict` (raw JMdict data close to the source XML shape), this is the fully-assembled data a client
would render: resolved furigana, sense groups with tags, applicable-form restrictions, linked example
sentences, and alternate-forms tables -- the same assembly `sumatora-render-entry.py` uses to print a
dictionary card, just as structured JSON instead of terminal text.

## Layout

```
entries/{shard}/{seq}.json              language-neutral: forms + furigana, sense-group tags,
                                         per-sense applicable-forms and Japanese example text,
                                         alternate-forms table
translations/{lang}/{shard}/{seq}.json  per language: glosses per sense, example translations
                                         (only written when that language has at least one gloss)
```

`shard = seq // 10000`, `seq` is the JMdict sequence number (`Entry.source_key`) -- files line up 1:1
with `gitmdict`'s own sharding, by design.

This repository is regenerated and pushed automatically by SumatoraIndex's monthly release workflow.
Manual edits here will be overwritten on the next sync.
